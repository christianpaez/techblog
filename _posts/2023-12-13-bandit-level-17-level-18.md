### SSH Connection with Private Key

Now that we have the private key, let's connect to the Bandit server using SSH:

```bash
ssh -i private.key bandit17@bandit.labs.overthewire.org -p 2220
```

The `-i` flag specifies the private key file, and `-p` specifies the port.
